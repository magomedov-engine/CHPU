# ♻️ Урок 9. Токарные циклы (Fanuc)

> [!abstract] О чём урок
> Токарные циклы позволяют одной-двумя строками снять весь припуск, проточить канавку или нарезать резьбу.
> - **G71 / G72 / G73** — черновые циклы по контуру, **G70** — чистовой;
> - **G74 / G75** — глубокое сверление по оси и канавки;
> - **G76 / G92** — резьба;
> - **G90 / G94** токарные — простые циклы точения и подрезки.
>
> Форматы — для **Fanuc 0i** (двухстрочная запись), наиболее распространённой.
>
> ⏱ ~40 минут

---

## 1. G71 — черновой цикл продольного точения

![[gc-g71.svg]]

```gcode
G00 X48. Z2.                         (точка старта — вне заготовки)
G71 U2. R0.5                         (U — съём на сторону, R — отвод)
G71 P120 Q220 U0.4 W0.1 F0.25        (P..Q — кадры контура, U/W — припуски)
N120 G00 X16.8                       (первый кадр контура — только X!)
N130 G01 Z0. F0.1
...
N220 X46. Z-63.                      (последний кадр контура)
```

| Параметр | Строка | Значение |
|---|---|---|
| **U** (1-я строка) | Δd | Глубина резания **на сторону** за проход (мм) |
| **R** | e | Отвод от материала после прохода |
| **P / Q** | ns / nf | Номера **первого и последнего** кадров контура |
| **U** (2-я строка) | Δu | Припуск на чистовую **по диаметру** (U0.4 = 0,2 на сторону) |
| **W** | Δw | Припуск на чистовую **по Z** |
| **F, S** | — | Подача/скорость для **черновых** проходов (F внутри контура — для G70) |

> [!warning] Правила для контура G71 (тип I)
> 1. **Первый кадр** контура (ns) — движение **только по X** (`G00 X16.8` или `G01 X16.8`).
> 2. Контур **монотонный**: X только **растёт** (для наружной обработки) — без «впадин». Канавки G71 типа I не делает (для этого тип II или G73).
> 3. Точка старта цикла — **вне заготовки**: X больше заготовки, Z перед торцом.
> 4. Номера кадров P/Q должны **существовать** и стоять **сразу после** второй строки G71.

> [!info] Внутренняя обработка (расточка)
> Тот же G71, но точка старта — **внутри** отверстия (X меньше отверстия), контур — X **уменьшается**, а припуск **U отрицательный**: `U-0.4`.

## 2. G70 — чистовой цикл

```gcode
G00 G42 X48. Z2.
G70 P120 Q220
G00 G40 X200. Z150.
```

Проходит контур N120…N220 **точно**, с подачами и скоростями, указанными **внутри контура**. Обычно выполняется **другим** (чистовым) резцом.

## 3. G72 и G73

| Цикл | Как режет | Когда |
|---|---|---|
| **G72** | Слоями **поперёк** — как подрезка торца, проходы по X | Короткие детали большого диаметра (фланцы, диски) |
| **G73** | Повторяет **форму контура** несколько раз, смещаясь к нему | Заготовки, уже близкие по форме: поковки, отливки, а также контуры с впадинами |

```gcode
G72 W2. R0.5
G72 P300 Q400 U0.4 W0.1 F0.25

G73 U3. W0. R3                     (общий припуск по X 3, по Z 0, 3 прохода)
G73 P500 Q600 U0.4 W0.1 F0.2
```

## 4. G75 — канавки (и G74 — сверление по оси)

### G75 — прорезка канавки с отскоками

```gcode
G00 X34. Z-30.                     (над канавкой, ширина резца 3 мм)
G75 R0.5                           (отскок для слома стружки)
G75 X22. Z-34. P1500 Q2500 F0.05   (до Ø22, канавка от Z-30 до Z-34)
```

| Параметр | Значение |
|---|---|
| **X** | Диаметр дна канавки |
| **Z** | Конечная координата по Z (если канавка шире резца) |
| **P** | Глубина одного врезания по X, **мкм на сторону** (P1500 = 1,5 мм) |
| **Q** | Сдвиг по Z между врезаниями, **мкм** (Q2500 = 2,5 мм — меньше ширины резца) |

Резец врезается на P, отскакивает на R (ломает стружку), врезается дальше — до дна; затем сдвигается на Q и повторяет.

### G74 — глубокое сверление по оси (на токарном)

```gcode
G00 X0. Z3.
G74 R0.5
G74 Z-40. Q5000 F0.12              (сверлить до Z-40 клевками по 5 мм)
```

## 5. Резьба: G76 и G92

### G76 — многопроходный цикл резьбы ⭐

```gcode
G97 S800 M03
G00 X22. Z5.
G76 P020060 Q50 R0.05
G76 X18.16 Z-20. P920 Q300 F1.5
```

**1-я строка:**

| Параметр | Значение |
|---|---|
| **P020060** | `02` — число **чистовых** проходов; `00` — сбег (фаска выхода) в десятых шага; `60` — **угол профиля** (60° метрическая) |
| **Q50** | Минимальная глубина прохода, **мкм** (0,05 мм) |
| **R0.05** | Припуск на чистовой проход, мм |

**2-я строка:**

| Параметр | Значение |
|---|---|
| **X** | **Внутренний** диаметр резьбы (наружной) |
| **Z** | Конец резьбы |
| **R** | Разница радиусов для **конической** резьбы (0 — цилиндрическая, не пишут) |
| **P920** | Высота профиля, **мкм на сторону** (≈ 0,6134 × шаг) |
| **Q300** | Глубина **первого** прохода, мкм |
| **F1.5** | **Шаг** резьбы (на токарном в G99 F = шаг) |

Стойка сама делает 8–12 проходов с **уменьшающейся** глубиной (одинаковая площадь стружки), врезаясь по боковой стороне профиля.

### G92 — простой цикл резьбы (один проход на строку)

```gcode
G00 X22. Z5.
G92 X19.4 Z-20. F1.5
X19.0
X18.7
X18.45
X18.3
X18.2
X18.16
G00 X200. Z150.
```

Каждая строка — **один проход** на заданный диаметр. Нагляднее и удобнее для правки (можно добавить «зачистной» проход), но длиннее.

> [!tip] Подгонка резьбы
> Если резьбовое кольцо **ПР не идёт** — резьба «толстая». Добавляют износ X резьбового резца **в минус** (например, −0,04) и **повторяют** цикл: резец пройдёт по уже нарезанной канавке (обороты те же!) и снимет немного. Поэтому деталь из патрона до проверки калибром **не снимают**.

## 6. Токарные G90 и G94 — не путать с фрезерными!

| Код | На токарном (Fanuc, система A) | На фрезерном |
|---|---|---|
| **G90** | Простой цикл **продольного точения** (один проход «туда-отвод-обратно») | Абсолютные координаты |
| **G94** | Простой цикл **подрезки торца** | Подача мм/мин |

```gcode
(Токарный G90 — три прохода точения до Ø40, Ø36, Ø32 на длину 30)
G00 X46. Z2.
G90 X40. Z-30. F0.25
X36.
X32.
G00 X200. Z150.
```

> [!info] Системы G-кодов на токарных Fanuc
> У токарных стоек Fanuc есть **системы A, B, C**. В системе **A** (самая частая) абсолютные/относительные задаются адресами **X/U, Z/W**, а G90 — цикл точения. В системах B и C G90/G91 — абсолютные/относительные, как на фрезерном. Какая система на вашем станке — смотрят в документации; почти везде — **A**.

---

## 7. Итоги урока

> [!summary] Запомни
> 1. **G71** — черновое продольное точение по контуру: `G71 U(съём) R(отвод)` / `G71 P Q U(припуск Ø) W F`. Контур монотонный, первый кадр — только X.
> 2. **G70 P Q** — чистовой проход по тому же контуру.
> 3. **G72** — поперечными слоями, **G73** — повторением формы (поковки, впадины).
> 4. **G75** — канавки (P, Q в мкм), **G74** — сверление по оси.
> 5. **G76** — резьба: P (чистовые проходы/сбег/угол), Q мин. проход; X внутр. Ø, P высота профиля (мкм), Q первый проход (мкм), F шаг. **G92** — резьба по проходу на строку.
> 6. **G90/G94 на токарном** — простые циклы точения/подрезки, а не абсолютные координаты!

## ❓ Проверь себя

> [!question]- 1. Что означают U в первой и во второй строке G71?
> В первой — глубина резания на сторону за проход. Во второй — припуск на чистовую обработку по диаметру.

> [!question]- 2. Какие требования к контуру G71 типа I?
> Первый кадр — только по X, контур монотонный (X только растёт для наружной обработки), номера P и Q существуют.

> [!question]- 3. Как G70 узнаёт, где контур?
> По номерам кадров P (первый) и Q (последний) — тем же, что и в G71.

> [!question]- 4. Расшифруйте `G76 X9.85 Z-25. P1073 Q300 F1.75`. Какая это резьба?
> Внутренний диаметр 9,85, длина до Z−25, высота профиля 1,073 мм, первый проход 0,3 мм, шаг 1,75.
> Наружный диаметр ≈ 9,85 + 2 × 1,073 ≈ 12 → это **M12** с крупным шагом 1,75 (высота профиля 0,6134 × 1,75 ≈ 1,073 ✓).

> [!question]- 5. Резьбовое кольцо ПР не навинчивается. Что делать?
> Не снимая деталь, ввести в износ X резьбового резца небольшое отрицательное значение и повторить цикл резьбы.

> [!question]- 6. Чем G90 на токарном отличается от G90 на фрезерном?
> На токарном (система A) — простой цикл продольного точения, на фрезерном — абсолютные координаты.
