# 📖 Урок 13. Справочник G- и M-кодов + глоссарий

> [!abstract] Как пользоваться
> Шпаргалка для стоек **Fanuc** и совместимых (Haas, Mitsubishi, Балт-Систем…). На конкретном станке **проверяйте по инструкции** — особенно M-коды, которые у каждого производителя свои. Поиск по странице — `Ctrl+F`.

## 3. M-коды (типовые)

| Код | Значение |
|---|---|
| **M00** | Программный останов (всегда) |
| **M01** | Условный останов (Optional Stop) |
| **M02** | Конец программы (без возврата) |
| **M03 / M04 / M05** | Шпиндель по часовой / против / стоп |
| **M06** | Смена инструмента (фрезерный) |
| **M07** | Туман / доп. СОЖ (зависит от станка) |
| **M08 / M09** | СОЖ вкл / выкл |
| **M19** | Ориентация шпинделя |
| **M29** | Жёсткое нарезание резьбы (Fanuc) |
| **M30** | Конец программы с возвратом в начало |
| **M98 / M99** | Вызов подпрограммы / возврат |
| **M10 / M11, M68 / M69…** | Зажим/разжим патрона, стола — **зависит от станка** |
| **M88 / M89 (Haas)** | СОЖ через шпиндель — **зависит от станка** |

## 4. Адреса

| Адрес | Значение |
|---|---|
| O | Номер программы |
| N | Номер кадра |
| G / M | Подготовительная / вспомогательная функция |
| X Y Z | Линейные оси (на токарном X — диаметр) |
| A B C | Поворотные оси |
| U W | Приращения X / Z (токарный) |
| I J K | Центр дуги от начальной точки; параметры циклов |
| R | Радиус дуги; плоскость R в цикле |
| F | Подача; шаг резьбы |
| S | Обороты / скорость резания |
| T | Инструмент (токарный: позиция + корректор) |
| H / D | Корректор длины / радиуса |
| P Q | Пауза, подпрограмма, кадры контура, клевок |
| L / K | Число повторений |

## 6. Формулы на одной странице

| Что | Формула |
|---|---|
| Обороты | **n = 1000 · Vc / (π · D)** |
| Подача фрезы | **F = fz · z · n** |
| Подача сверла (мм/мин) | **F = f · n** |
| Подача метчика | **F = n · P** (P — шаг) |
| Высота профиля метрической резьбы (наружной) | **h ≈ 0,6134 · P** |
| Сверло под метчик | **≈ d − P** |
| Координаты отверстия на окружности | **X = Xц + R·cos α, Y = Yц + R·sin α** |
