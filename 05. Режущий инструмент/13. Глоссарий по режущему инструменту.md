## Шпаргалка: обозначение пластины (ISO 1832)

| Поз. | Что | Частые значения |
|---|---|---|
| 1 | Форма | C 80°, D 55°, V 35°, W тригон, T 60°, S 90°, R круг |
| 2 | Задний угол | N 0°, B 5°, C 7°, P 11° |
| 3 | Класс допуска | M (обычная), G (шлифованная) |
| 4 | Тип / крепление | G, M, A (с отверстием), T (под винт), N (без отверстия) |
| 5 | Размер кромки | 06, 09, 11, 12, 15, 16 |
| 6 | Толщина | 02 = 2,38; T3 = 3,97; 04 = 4,76; 06 = 6,35 |
| 7 | Радиус | 02 = 0,2; 04 = 0,4; 08 = 0,8; 12 = 1,2; 16 = 1,6 |
| 8 | Стружколом | F — чистовая, M — средняя, R — черновая (у каждой фирмы свои коды) |

## Шпаргалка: износ → решение

| Износ | Решение |
|---|---|
| Быстрый по задней | ↓ Vc, износостойкий сплав |
| Лунка | ↓ Vc, Al₂O₃ |
| Выкрашивание | Жёсткость, ↓ f на входе, вязкий сплав |
| Нарост | ↑ Vc, острая пластина, СОЖ |
| Деформация | ↓ Vc и f, твёрдый сплав |
| Проточина | Менять ap, меньший κr |
| Термотрещины | Сухо или обильная СОЖ, вязкий сплав |
| Поломка | ↓ нагрузка, менять вовремя, проверить подкладку |
