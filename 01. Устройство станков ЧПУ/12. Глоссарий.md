# 📖 Глоссарий: устройство станков с ЧПУ

> [!abstract] Как пользоваться
> Термины по алфавиту. В скобках — **английский** вариант (он часто встречается на экранах стоек и в инструкциях). Ссылка ведёт на урок, где термин разобран подробно.

## Коды, которые встречались в модуле

| Код | Значение |
|---|---|
| **G00** | Ускоренное перемещение |
| **G01** | Линейная интерполяция (резание по прямой) |
| **G02 / G03** | Круговая интерполяция по / против часовой |
| **G20 / G21** | Дюймы / миллиметры |
| **G41 / G42** | Коррекция на радиус слева / справа (D) |
| **G43** | Коррекция на длину инструмента (H) |
| **G54–G59** | Рабочие системы координат |
| **G90 / G91** | Абсолютные / относительные координаты |
| **G94 / G95** | Подача в мм/мин / мм/об |
| **M03 / M04 / M05** | Шпиндель по часовой / против часовой / стоп |
| **M06** | Смена инструмента |
| **M08 / M09** | СОЖ вкл / выкл |
| **M19** | Ориентация шпинделя |
| **M01** | Условный (опциональный) останов |
| **M30** | Конец программы |
| **T0101** | (токарный Fanuc) инструмент 1, корректор 1 |

> [!info] Это не полный список
> Подробно G- и M-коды будут разобраны в модуле по программированию. Номера некоторых M-кодов (например, СОЖ через шпиндель) **зависят от производителя станка** — смотрите инструкцию конкретного станка.
