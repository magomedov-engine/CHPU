## Шпаргалка: инструмент ↔ допуск

| Допуск размера | Инструмент |
|---|---|
| ≥ 0,5 мм | Штангенциркуль 0,1 |
| 0,2 … 0,5 мм | Штангенциркуль 0,05 |
| 0,1 … 0,2 мм | Цифровой штангенциркуль / микрометр |
| 0,02 … 0,1 мм | Микрометр 0,01, нутромер с ИЧ 0,01 |
| < 0,02 мм | Микрометр / нутромер 0,001, рычажная скоба, калибры |
| Серия | Калибры ПР/НЕ |
| Биение, соосность | Индикатор |
| Резьба | Калибры ПР/НЕ, резьбомер |

## Шпаргалка: как читать

| Прибор | Формула отсчёта |
|---|---|
| **Штангенциркуль** | целые мм по штанге + № совпавшей риски нониуса × цена деления |
| **Микрометр** | целые мм (верх стебля) + 0,5 (если открыта нижняя) + барабан × 0,01 |
| **Индикатор** | малая стрелка (мм) + большая стрелка × 0,01 |
| **Нутромер** | номинал настройки ± отклонение (по часовой — меньше, против — больше) |
