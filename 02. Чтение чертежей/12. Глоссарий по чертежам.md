## Шпаргалка обозначений

| Обозначение | Значение |
|---|---|
| `Ø` · `R` · `□` · `S` | Диаметр · радиус · квадрат · сфера |
| `1×45°` / `C1` | Фаска |
| `▷1:5` · `∠1:10` | Конусность · уклон |
| `±0,1` · `-0,1` · `+0,1` | Отклонения |
| `H7` / `h7` | Поле допуска отверстия / вала |
| `H7/k6` | Посадка |
| `Ra 1,6` | Шероховатость |
| `Ra 6,3 (√)` в углу | Шероховатость неуказанных поверхностей |
| `—` `⏥` `○` `⌭` | Прямолинейность, плоскостность, круглость, цилиндричность |
| `∥` `⊥` `∠` | Параллельность, перпендикулярность, наклон |
| `⌖` `◎` `⌯` | Позиционный, соосность, симметричность |
| `↗` `⌰` | Биение, полное биение |
| `M10` · `M10×1` · `-6g` / `-7H` · `LH` | Резьба крупная · мелкая · поле наружной / внутренней · левая |
| `G1/2` · `Tr20×4` · `UNC` | Трубная · трапецеидальная · дюймовая |
| `↧` `⌴` `⌵` `THRU` `4X` `TYP` | Глубина, цековка, зенковка, насквозь, 4 шт., типовой |
| `HRC` · `HB` | Твёрдость по Роквеллу · по Бринеллю |
| `Хим.Окс.прм` · `Ц9.хр` · `Ан.Окс` | Оксидирование · цинкование · анодирование |
| `ГОСТ 30893.1-m` / `ISO 2768-m` | Общие допуски, средний класс |
